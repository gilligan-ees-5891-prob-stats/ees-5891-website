Linear Regression with Discrete Variables

Linear Regression with Discrete Variables

  • Continuous variables:
    • Temperature, mass, pH, silica content, grain size, …
  • Discrete variables:
    • Count data: How may earthquakes, volcanic eruptions, hurricanes, …
    • Categorical data: Mineral type (quartz, calcite, biotite, …), species, fault type, …
  • Four possibilities:
    • Continuous independent, continuous dependent
    • Continuous independent, discrete dependent
    • Discrete independent, continuous independent
    • Discrete independent, discrete dependent
  • Categorical vs. Ordinal discrete variables:
    • Ordinal: count, ordered categories (age-range, etc.)
      • One measurement can be greater or less than another
    • This doesn’t make sense with unordered categories:
      • Mineral type, species, …

Discrete Variables

  • Ordinal independent variables:
    • Count,
    • Mostly, treat them like continuous variables
  • Categorical independent variables:
    • “One-hot” encoding (dummy variables)
      • If \(x\) has \(k\) possible values, replace \(x\) with \(k\) different variables,
        • One and only one is 1, and the rest are 0
        • Instead of one column, “mineral,” have “quartz”, “calcite”, “K-feldspar”, “plagioclase feldspar”, “mica”, “amphibole”, …
  • Ordinal dependent variables:
    • Count data:
      • \(x \sim \mathcal{D}\), a discrete distribution (Bernoulli, Binomial, Poisson, etc.)
      • Parameters:
        • Poisson has a continuous parameter \(\lambda \ge 0\).
        • Bernoulli, Binomial, etc. have a continuous parameter probability \(p: 0 \le p \le 1\).
          • Logistic regression
  • Categorical dependent variables:
    • Multinomial distributions.
      • We won’t cover this.

Logistic Regression

  • Linear regression:

    \[ y = \beta_0 + \beta_1 x + \varepsilon \]

    • Count data:

      \[ \begin{align} y \sim& \text{Binomial}(p(x), n) \\ \mathbb{P}(y = k | p(x), n) =& \left(n \atop k \right) p(x)^k (1 - p(x))^{n - k} \\ p(x) \sim& \mathcal{D}(\theta, x) \end{align} \]

      We’re used to regression of the form

      \[ p(x) = \beta_0 + \beta_1 x + \varepsilon \]

      but how do we constrain \(p\) to be between 0 and 1?

  • Logit function:

    \[ \begin{align} \mathrm{logit}(p) =& \ln \frac{p}{1 - p} \\ \mathrm{logit}^{-1}(x) =& \frac{e^x}{e^x + 1} \end{align} \]

    • Logit maps the interval \((0,1)\) to the interval \((-\infty, \infty)\)
    • Inverse-logit maps the interval \((-\infty, \infty)\) to the interval \((0, 1)\)

  • Logistic regression:

    \[ \begin{align} y \sim& \text{Binomial}(x, n) \\ z =& \beta_0 + \beta_1 x + \varepsilon \\ p =& \mathrm{logit}^{-1}(z) \end{align} \]

The Logit Function

  • Logit function:

    \[ \begin{align} \mathrm{logit}(p) =& \ln \frac{p}{1 - p} \\ \mathrm{logit}^{-1}(x) =& \frac{e^x}{e^x + 1} \end{align} \]

  • Logistic regression:

    \[ \begin{align} y \sim& \text{Binomial}(x, n) \\ z =& \beta_0 + \beta_1 x + \varepsilon \\ p =& \mathrm{logit}^{-1}(z) \end{align} \]

    • \(z\) ranges anywhere between \(-\infty\) and \(\infty\).
    • The \(\mathrm{logit}^{-1}(z)\) function maps it onto the \((0,1)\) interval suitable for a probability.

Generalized Linear Models

Generalized Linear Models

  • Linear Regression Model:

    \[ \begin{align} y_i =& \beta_0 + \sum{j = 1}^p \beta_j\: x_{i,j} + \varepsilon_i \\ E(Y | X) =& \beta_0 + \sum{j = 1}^p \beta_j\: x_{i,j} \end{align} \]

  • Generalized Linear Model:
    • Three parts:
      1. A distribution \(\mathcal{D}\) for \(Y\)
        • Bernoulli (coin-toss), Binomial, Poisson, etc.
      2. A linear predictor \(\eta_i = \beta_0 + \sum_j \beta_j\: x_{i,j}\)
      3. A link function \(g(\eta)\)
        • logit, logarithm, etc.
      \[ \begin{align} y_i \sim& \mathcal{D}\left(\mu = g^{-1}(\eta_i)\right) \\ \eta_i =& \beta_0 + \sum_{j = 1}^p \beta_j\: x_{i,j} + \varepsilon_i\\ E(y_i | x_{i,j}) =& g^{-1}\left( \beta_0 + \sum_{j = 1}^p \beta_j\: x_{i,j} \right) \end{align} \]

Link Functions & Probability Distributions

  • Three parts:
    1. A distribution \(\mathcal{D}\) for \(Y\)
      • Bernoulli (coin-toss), Binomial, Poisson, etc.
    2. A linear predictor \(\eta_i = \beta_0 + \sum_j \beta_j\: x_{i,j}\)
    3. A link function \(g(\eta)\)
      • logit, logarithm, etc.
  • The parameters \(\theta\) of \(\mathcal{D}(\theta)\) should be related to \(g\) so \(\mu = g^{-1}(\eta_i)\) is the mean for the probability distribution \(\mathcal{D}(\theta)\).
    • This means \(\mu = g^{-1}(\eta_i)\) is the expectation value for \(y_i\)

  • Examples:

    Distribution Values Link Link function
    Normal \((-\infty, \infty)\) Identity \(g(\mu) = \mu\)
    Gamma \([0, \infty)\) Negative inverse \(g(\mu) = -1 / \mu\)
    Poisson 0, 1, 2, … Log \(g(\mu) = \ln(\mu)\)
    Bernoulli 0, 1 Logit \(g(\mu) = \ln \left( \frac{\mu}{1 - \mu} \right)\)
    Binomial 0, 1, …, N Logit \(g(\mu) = \ln \left( \frac{\mu}{N - \mu} \right)\)

Hurricane Climatology

  • Cyclonic storm systems can be categorized as
    • Tropical (warm-core, barotropic).
    • Extratropical (cold-core, baroclinic).
    • barotropic systems don’t exhibit wind shear, baroclinic systems do.
  • Hurricanes are barotropic tropical cyclones, but they can have baroclinic influences.
  • Challenge: Use logistic regression to predict which hurricanes have baroclinic influences.
  • Theoretical basis:
    • Most hurricanes form in the deep tropics, over uniformly warm seas: barotropic, no wind shear.
    • Some hurricanes form at higher latitudes, where interaction with midlatitude jet streams affect them (baroclinic).
  • Use logistic regression against the latitude at which the hurricane formed to predict baroclinic influence.

Assessing the Quality of a Logistic Model

  • We measure linear regression models by the sum of the squares of the residuals (errors)
  • But a logistic model predicts a probability of something that’s 0 or 1. How do you measure the error?
  • One way: ROC (Receiver Operating Characteristic) curves.
    1. Split your data into training and test sets.
      • You can also use \(k\)-fold cross-validation.
    2. Fit your model to the training set.
    3. Generate predictions for the test set.
      • Now you have a list of predicted probabilities and observed categories
    4. Vary a threshold \(x\): Predict that a hurricane is baroclinic if \(p_{\text{baroclinic}} > x\).
      • For each value of \(x\), count false positives and false negatives.
  • ROC Curve
    1. Plot sensitivity vs 1 − specificity.
      • sensitivity: Probability of correct test if \(H_0\) is false.
        • True positive if “positive” is the correct answer.
        • Probability of correctly identifying Baroclinic storms.
      • specificity: Probability of correct test if \(H_0\) is true.
        • True negative if “negative” is the correct answer.
        • Probability of correctly identifying Tropical storms.

Modeling Hurricanes

  • Hurricane landfalls clearly follow a Poisson distribution. The average rate of landfalls is 1.737931.
  • However, we don’t think the number is purely random: climate factors are likely to influence the number of hurricanes.
    • SST: Average Sea-Surface Temperature in the Atlantic Ocean.
    • NAO: North-Atlantic Oscillation Index.
    • SOI: Southern Oscillation Index (related to El Niño).
    • SSN: Sun-spot number, which correlates with the brightness of the sun.

Forecast Skill

  • How do we know how good a forecasting model is?
  • Skill: how does the forecast model compare to a naïve model?

    • Naïve model: Every year has the same forecast: the average number of hurricanes 1.7

    • RMSE for the naive model is

      MSE_naive <- hurricanes |> 
  summarize(MSE = sum( (All - mean(All))^2 ) / (n() - 1)) |> 
  pull(MSE)

MSE_naive
      ## [1] 2.194732

  • MSE for our predictive model is

    MSE_skilled <- collect_metrics(results) |> 
  filter(.metric == "rmse") |> 
  mutate(MSE = mean^2) |> pull(MSE)
MSE_skilled
    ## [1] 2.119829

  • So, MSE for the naïve model is 2.19 and MSE for the predictive model is 2.12, which is 3.4% better.
